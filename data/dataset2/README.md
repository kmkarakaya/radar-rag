# Data Klasörü

Bu klasör RAG (Retrieval-Augmented Generation) sistemi için gerekli veri dosyalarını barındırmak üzere ayrılmıştır. 

Sistemi kullanacak kişiler kendi `.txt`, `.md`, `.pdf`, `.doc` veya `.docx` dosyalarını bu dizine (veya alt klasörlerine) yerleştirebilirler. JSON dosyaları desteklenmez ve indekslemede atlanır.
