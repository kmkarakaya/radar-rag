RAGStation Public API Example

Static browser example aligned with the current /v1/rag contract. It sends tenant and user headers, checks collection readiness before enabling query actions, and surfaces rate-limit, model metadata, plus request diagnostics.

Contract note

POST /query returns an answer, embeddingModel, chatModel, and the generation-context sources. POST /retrieve returns embeddingModel plus evidence-only results and can expose a broader retrieval set.
